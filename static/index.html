快速开始

  1. 抓包获取乐跑请求的 data 参数。
  2. POST /api/capture/import 预览 → POST /api/capture/save 保存。
  3. GET /api/routes 查看可用场地。
  4. POST /api/submit 直接提交。

接口一览

方法路径说明
GET/api/config运行状态
GET/api/routes可用场地
POST/api/capture/import解析抓包 data
POST/api/capture/save保存乐跑配置
GET / DELETE/api/capture/config查看 / 清除配置
POST/api/capture/terms可选学期
POST/api/capture/records历史记录
POST/api/user/run/start开始倒计时
GET/api/user/run/status会话状态
POST/api/user/run/cancel取消会话
POST/api/submit提交跑步
POST/api/submit/with-record用历史记录提交
GET/api/runs提交历史
